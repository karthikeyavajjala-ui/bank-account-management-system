# Bank Account Management System

**An OOP-Based Java AWT Application**

A beginner-friendly B.Tech CSE mini project that demonstrates Java OOP through a working desktop bank-account application. The interface uses **Java AWT only**; there is no Swing, JavaFX, database, or third-party dependency.

## Requirements

- JDK 8 or later
- A desktop environment capable of displaying AWT windows
- No external libraries

## Compile and run

Open a terminal in this project folder:

```bash
javac -encoding UTF-8 *.java
java Main
```

Or use the included launch scripts:

- Windows: double-click `run.bat` (or run it from Command Prompt)
- macOS/Linux: run `./run.sh`

The project has **no Java package declaration**, so the source files can be compiled together with the command above.

## How to try the application

1. Start the application. The dashboard shows account, balance, and transaction totals.
2. Choose **Create Account**. Enter a name, 10-digit phone number, address, account type, and initial deposit (zero is allowed).
3. The program generates an account number such as `ACC1001` and a customer ID such as `CUST1001`.
4. Use **Deposit Money**, **Withdraw Money**, **Check Balance**, **Account Details**, **Transaction History**, **All Accounts**, and **Delete Account** to demonstrate the working features.
5. For a withdrawal error demonstration, create a Savings Account with a small balance and request a larger withdrawal. For a Current Account, withdrawals can use the default ₹10,000 overdraft limit.
6. Choose **Exit Application** and confirm to close.

### Validation and account rules

- Customer name and address cannot be blank.
- Phone number must contain exactly 10 digits (Indian phone-number format for this project).
- Initial deposit must be zero or greater. Deposit and withdrawal transactions must be greater than zero.
- Amounts are rounded to two decimal places.
- Account numbers are generated by the bank and searched without case sensitivity.
- Savings Account interest is shown as a **4% simple annual estimate**; it is not credited to the balance.
- Current Account withdrawals may use the default **₹10,000 overdraft limit**. The account balance can therefore become negative, but not below the permitted limit.

## Local file storage

Successful changes are automatically saved in `bank-data.dat` in the current working directory using standard Java object serialization. The file is created when the first account or transaction is saved. Run the program from this project folder so it is easy to find.

To reset the demonstration data, close the application and delete `bank-data.dat`. This is a teaching demo: the file is not encrypted and must not be used for real customer or banking data.

## Notes

- The GUI is built from `Frame`, `Panel`, `Label`, `TextField`, `TextArea`, `Button`, `Choice`, `Dialog`, `CardLayout`, and AWT event listeners.
- The GUI calls the `Bank` business-logic class; it does not change account balances directly.
